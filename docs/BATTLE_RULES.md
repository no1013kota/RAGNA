# RAGNA Online 戦闘ルール・使い魔データ

この文書は、ギルドバトルの**戦闘中に何が起きるか**を定める正式な基準です。あわせて、全使い魔の能力値とスキルを掲載します。

## 0. 他の文書との棲み分け

| 文書 | 担当範囲 |
| --- | --- |
| この文書 | 戦闘ルール（行動順、ダメージ分類、クリティカル、戦闘不能、効果時間、状態異常・バフ・デバフの分類）と、全使い魔の能力値・スキル |
| [ゲーム仕様書](GAME_SPEC.md) | ギルドの設立・運営、使い魔の入手・育成・売却、パネル、チャンネル、データベース、運用手順 |

判断に迷ったときの原則は次のとおりです。

- **「戦闘中の判定」はこの文書が決めます。** 行動順、ダメージの種類、効果の重複、状態異常の分類など。
- **「保存・表示・運用」はゲーム仕様書が決めます。** DBの内部名、Embedの見せ方、持ち時間、ログ、パネル操作など。
- 同じことを両方に書きません。ゲーム仕様書の戦闘関連の節は、この文書へのポインタだけを持ちます。

数値の唯一の定義は `data/master/` のJSONです。この文書とJSONは常に同じ内容へ更新します（[アーキテクチャ](ARCHITECTURE.md)の「変更時のルール」）。

## 1. ターン・ラウンド・行動順

### ターン

1体の使い魔が行動する単位。

### ラウンド

使い魔の行動が一巡する単位。

### 行動順

- 現在SPDが高い使い魔から行動する
- 基礎SPDは原則として全使い魔で重複させない
- バフ/デバフにより現在SPDが同値になった場合、基礎SPDが高い方を先にする
- 同じ使い魔同士など、基礎SPDまで同じ場合は先行をランダムで決定する

### ラウンド途中でSPDが変化した場合

- そのラウンドですでに行動済みの使い魔は並び替えない
- まだ行動していない使い魔だけを、現在SPDで再度並び替える
- 行動済みの使い魔がSPD変化によって再行動することはない

### 最低値

- ATK最低値：0
- SPD最低値：0

## 2. 通常攻撃・ACTIVE・PASSIVE

### 通常攻撃

- 通常攻撃ダメージ＝現在ATK
- 対象は原則として生存している敵から自由に選択する
- 挑発中は例外あり

### ACTIVE

- 原則としてACTIVE使用後も通常攻撃できる
- 攻撃権を消費するACTIVEには、必ず「※このターンの攻撃を消費する」と記載する

### 挑発とACTIVEの関係

- 挑発が強制するのは「通常攻撃」の対象のみ
- ACTIVEそのものの対象は挑発で強制されない
- スルト「終末の進軍」のように、ACTIVE自体の効果として攻撃を行う「攻撃型ACTIVE」は、挑発の対象強制を受けない
- 攻撃型ACTIVEでは、スキル本文どおり自由に攻撃対象を選べる
- ACTIVEを使用しただけで、そのターンの通常攻撃まで挑発から解放されるわけではない
- ACTIVE使用後に通常攻撃が残っている場合、その通常攻撃は挑発の影響を受ける

例：

- レヴィアタンの挑発中にスルトが「終末の進軍」を使用 → 終末の進軍の2回攻撃は自由に対象を選べる
- レヴィアタンの挑発中にルシファーが「明星の加護」を使用 → その後の通常攻撃はレヴィアタンを対象にしなければならない

### PASSIVE

- 条件を満たした時に自動発動する
- 回数制限が書かれていないPASSIVEは、条件を満たすたびに発動する

## 3. ダメージ分類

### 攻撃ダメージ

「攻撃」として処理されるダメージ。

例：

- 通常攻撃
- スルト「終末の進軍」の2回攻撃
- その他、攻撃型ACTIVE

特徴：

- クリティカル対象
- 「攻撃ダメージ軽減」の対象

### スキルダメージ

スキル本文に固定値で記載される直接ダメージ。

例：

- ヨルムンガンド「世界毒」の4ダメージ
- アバドン「奈落崩壊」の5ダメージ
- イフリート「灼熱」の6ダメージ

特徴：

- クリティカルは発生しない
- 攻撃ダメージ軽減の対象外

### 継続ダメージ

毒など、一定期間発生するダメージ。

特徴：

- クリティカルは発生しない
- 攻撃ダメージ軽減の対象外

### 即死

ダメージではなく、対象を直接戦闘不能にする処理。

例：

- ヘル「死の宣告」

---

## 4. クリティカル

- クリティカルが発生するのは「攻撃」として処理されるものだけ
- スキルダメージ、継続ダメージ、即死にはクリティカルは発生しない
- クリティカル時は攻撃ダメージを1.5倍する
- ダメージ軽減がある場合、先にクリティカル計算を行い、その後で軽減する

例：

```text
ATK10の攻撃がクリティカル
→ 15ダメージ
→ 攻撃ダメージ-2を持つ対象
→ 最終13ダメージ
```

クリティカル発生率は10%、1.5倍後の小数は四捨五入します（`data/master/balance.json` の `critical_chance_permille` と `critical_multiplier`）。

## 5. 戦闘不能・蘇生

### 戦闘不能

HPが0以下になると戦闘不能。

### 蘇生後の行動

- 蘇生された使い魔が、そのラウンドでまだ行動していなければ、現在の行動順へ復帰し、そのラウンド中に行動できる
- すでにその使い魔の行動が終了していた場合、そのラウンドでは再行動しない

### 戦闘不能中の付与効果

以下の効果は戦闘不能になっても消えず、保存される。

- バフ
- デバフ
- 状態異常
- 保護効果
- その他の持続効果

蘇生した場合も、戦闘不能直前の付与状態を維持したまま復帰する。

### 戦闘不能中の残りターン

- 戦闘不能中でも、その使い魔の本来の行動順が来た時に持続ターンを1減少させる
- 戦闘不能中は行動しないが、効果時間は経過する

---

## 6. 同時処理の基本順序

同時に複数の効果が関係する場合、基本的に以下の順で処理する。

1. ダメージ確定
2. 戦闘不能判定
3. 戦闘不能を条件とするPASSIVE
4. 蘇生などの処理
5. 攻撃後効果

## 7. 効果時間・重複ルール

### 効果時間

- 「（2ターン）」など、記載されたターン数だけ持続する
- 持続時間の記載がない持続効果は、バトル終了まで継続する
- そのため「バトル終了まで継続」と毎回記載する必要はない

### 持続ターンの減少

- 原則として、その効果を受けている使い魔の行動終了時に1減少する
- 戦闘不能中は、その使い魔の本来の行動順が来た時に1減少する

### バフ・デバフの重複

- 異なる使い魔・異なる効果源によるバフ/デバフは加算する

例：

```text
基礎SPD84 + SPD+12 - SPD-20 ＝ 現在SPD76
```

### 同一スキルの連続使用

- 同じ使い魔が、同じスキルを同じ対象へ再使用しても、同一効果は重複しない
- 再使用したときは残りターンを長い方へ揃える（付け直しで短くならない）

### 毒の重複

- 異なる使い魔が付与した毒は別効果として重複する

例：

```text
ベルゼブブの毒3 + ヨルムンガンドの毒2
→ 対象の毒処理時に合計5ダメージ
```

ヒュドラがいる場合：

```text
ベルゼブブ毒：4ダメージ×3ターン
ヨルムンガンド毒：3ダメージ×3ターン
→ 両方付与中は合計7ダメージ
```

- ヒュドラによる毒強化は、それぞれの毒に1回ずつ適用する

## 8. 状態異常・バフ・デバフ・保護効果

効果は次の5つに分類します。「状態異常無効」「状態異常解除」「デバフ解除」が何に効くかは、この分類で決まります。

| 分類 | 状態異常無効で防げる | 状態異常解除で解除できる | デバフ解除で解除できる |
| --- | :---: | :---: | :---: |
| 状態異常 | ○ | ○ | × |
| デバフ | × | × | ○ |
| バフ | × | × | × |
| 保護効果 | × | × | × |
| その他の特殊効果 | × | × | × |

### 状態異常

- **行動不能**：その使い魔の行動そのものを行えなくする。石化、魅了、凍結などは演出・スキル名として使用できるが、効果説明には「行動不能」と明記する
- **毒**：継続ダメージを与える
- **ACTIVE使用不能**：指定された期間、ACTIVEを使用できない（通常攻撃は可能）

### デバフ

状態異常とは別カテゴリ。

- ATK-○
- SPD-○
- 回復阻害（蘇生不可を含む）

状態異常無効では防げず、状態異常解除では解除できません。デバフ解除で解除できます。

### バフ

能力値をプラスする効果。

- ATK+○
- SPD+○

異なる効果源によるものは加算します。

### 保護効果

通常のバフとは分けて扱います。

- 状態異常無効
- 攻撃ダメージ軽減
- 戦闘不能耐性（HP1で耐える）
- 即死無効（将来追加予定）

状態異常無効は状態異常だけを防ぎます。ATK低下、SPD低下、回復阻害、挑発、即死は防ぎません。

### その他の特殊効果

- **挑発**：通常攻撃の対象を挑発使用者へ強制する。ACTIVEの対象は強制しない。攻撃型ACTIVEによる攻撃も挑発の対象強制を受けない。ただしACTIVE使用後の通常攻撃は、通常どおり挑発の影響を受ける
- **蘇生**：戦闘不能の使い魔を指定HPで戦線復帰させる
- **HP回復**：最大HPを超えて回復しない
- **即死**：ダメージを与えず、対象を直接戦闘不能にする
- **現在ATKの交換**：2体の現在ATKを入れ替える

## 9. 用語集

| 用語 | 意味 |
| --- | --- |
| 基礎HP | 戦闘開始時の元となる最大HP |
| 現在HP | 現在残っているHP |
| 基礎ATK | 使い魔本来のATK |
| 現在ATK | 基礎ATKに現在有効なバフ・デバフ・交換効果などを反映した値 |
| 基礎SPD | 使い魔本来のSPD |
| 現在SPD | 基礎SPDに現在有効なバフ・デバフを反映した値 |
| 通常攻撃 | 現在ATKを使用する通常の攻撃 |
| 攻撃 | クリティカル判定を持つ攻撃処理。通常攻撃だけでなく、一部の攻撃型ACTIVEも含む |
| 攻撃型ACTIVE | ACTIVEの効果そのものとして「攻撃」を行うスキル。挑発による通常攻撃の対象強制は受けない |
| スキルダメージ | クリティカルしない固定ダメージ |
| 継続ダメージ | 毒などによって一定期間発生するダメージ |
| 状態異常 | 行動不能、毒、ACTIVE使用不能 |
| デバフ | ATK低下、SPD低下、回復阻害など |
| バフ | ATK上昇、SPD上昇など |
| 回復阻害 | HP回復や蘇生を妨害するデバフ |
| 挑発 | 通常攻撃の対象を強制する特殊効果 |
| 行動不能 | その使い魔の行動そのものを行えなくする状態異常 |
| ACTIVE使用不能 | ACTIVEだけを使用できなくする状態異常。通常攻撃は可能 |
| ラウンド | 使い魔の行動が一巡する単位 |
| ターン | 1体の使い魔が行動する単位 |

## 10. ランク基準

| ランク | スキル | COST | 体数 |
| --- | --- | ---: | ---: |
| S | ACTIVE＋PASSIVE | 5 | 5 |
| A | ACTIVEまたはPASSIVE を1つ | 4 | 15 |
| B | スキルなし、またはACTIVEまたはPASSIVE を1つ | 3 | 20 |
| C | スキルなし | 2 | 10 |

- 合計50体です。
- BはAより単体汎用性を低めにし、特定編成・条件下で価値が上がる専門パーツを多くします。
- SPDは0〜100で管理し、数値が大きいほど先に行動します。
- COSTはランクごとに決まっています（S5／A4／B3／C2）。編成の合計COST上限は20です（`battle.max_total_cost`）。5体編成なら全Aでちょうど20、全Sは25で組めません。
- `性別` は性別条件を持つ効果（ベルフェゴール、リリス、セイレーン）の判定に使います。神話・伝承上の性別に基づく値で、人型でない個体や伝承上で性別が定まらない個体は「なし」です。「なし」の使い魔は性別条件の効果を受けません。
- `ID` は `data/master/familiars.json` のキーと、画像 `assets/familiars/<ID>.png` のファイル名に対応します。
