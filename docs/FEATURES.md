# 機能一覧

このファイルは、現在Discordで利用できる機能を説明します。各機能を直すファイルは
[設計・開発ガイド](ARCHITECTURE.md#機能とコードの対応表)を参照してください。

まだ公開されていないRAGNA Onlineの予定機能は、この文書の末尾に概要を記載しています。
詳しいルールは[ギルド・ギルドバトル仕様書](GAME_SPEC.md#11-ユーザーから見た公開予定機能)を参照してください。

## 利用者向け

- ATMパネル
  - 残高照会
  - 1,000 coin以上の送金
  - 送金メモ、受取人DM、運営ログ
- `/メンバー確認`
  - coin、VC時間、XP、招待ポイントなどの確認
- `/xp確認`
  - 月間・累計のVC時間とXPの確認
- `/ランキング`
  - coin、招待ポイント、VC時間、XP、アンケート評価の順位表示
- 招待ポイントパネル
  - ポイント確認
  - 精霊期間延長、宿屋無料率、coinへの交換
- 宿屋パネル
  - ツーショ、シークレット、プレミアムの作成
  - VC名、人数、公開状態、招待、出禁、共有の管理
  - 作成から15時間後の自動削除
- 問い合わせパネル
  - 問い合わせ先の選択と専用チャンネル作成
  - 終了後の再開、保存、削除
- 自己紹介チャンネル
  - 入力テンプレートの自動設置・再配置

## 評価員・運営向け

- `/召喚`
  - 精霊登録、クラス・期間設定、評価スレッド作成、ロール変更
- 評価パネル
  - 新規評価、追記、評価可能な対象者一覧
- 自動転生
  - 期限確認、評価保存、ロール変更、転生後アンケート
- `/転生`
  - 管理者による手動転生
- `/評価状況`
  - 総合評価に基づくクラス変更候補の表示
- `/クラス分布`
  - 現在のクラス別人数表示
- `/クラス変更`
  - ロール、DB、評価スレッドをまとめて更新
- `/招待報酬`
  - 招待ポイントの付与と利用ログ
- `/残高変更`
  - ユーザーまたはロール単位でcoin残高を変更
- `/ban`
  - ユーザーID指定のBANとログ保存

## 自動処理

- VC参加・退出・移動から滞在時間とXPを計算
- VC集計を5分ごと、およびBot終了時に保存
- 月替わりのVC・XP集計リセット
- ロール別coin月次報酬（停止期間後の追いつき・再実行時の二重支給防止）
- 負債状態に応じたロール変更
- 常設パネルが消えた場合の自動復旧
- メンバー参加・退出ログと関連データ整理
- 精霊期限とアンケート期限の定期確認

## 公開前：RAGNA Online

以下はコードの実装が完了し、テスト環境での確認を待っている機能です。
**環境変数 `GAME_ENABLED` が有効になるまでDiscord上には表示されません。**
本番確認が完了した機能から、上の「利用者向け」などの項目へ移します。

公開前に必要な準備は[ゲーム仕様書](GAME_SPEC.md#32-今後必要な準備物)を参照してください。
使い魔の能力値・スキル・性別はC〜Sランクの50体すべて登録済みです。使い魔画像は未登録ですが、
未登録のままでも公開できます（画像は共通の仮画像を表示します）。
戦闘ルールと使い魔データは[戦闘ルール・使い魔データ](BATTLE_RULES.md)を参照してください。

### ギルド

- ギルドの設立、参加申請、脱退
- メンバー募集チャンネルでの募集と参加申請
- メンバー追放、マスター譲渡、定員拡張、名称変更、解散
- ギルド専用チャンネルと閲覧権限の自動管理

### 使い魔

- coinを使ったガチャによる使い魔の入手
- 排出される使い魔と確率の確認
- 所有している使い魔の一覧・能力・画像の確認
- 図鑑での使い魔画像の閲覧
- すべての使い魔を集めたときのコンプリート報酬（ヘル）
- 同じ種類の使い魔を素材にした合成・レベルアップ（coin費用あり）
- 不要な使い魔の売却
- ギルドバトルで使用する使い魔の事前登録と、出場時の差し替え

### ギルドバトル

- ギルドマスターによる出場者セットと、出場者ごとの使い魔体数の割り当て
- 特定ギルドへの対戦申請と公開募集
- 対戦成立時のバトル専用チャンネル自動生成（終了後に自動削除）
- 最大5体どうしのターン制バトル（出場者1〜5人）
- 通常攻撃、アクティブスキル、パッシブスキル（使い魔50体・スキル40種）
- SPDの上下による行動順の変化、状態異常・デバフ・保護効果
- coinを賭けたバトル（額は申請・募集時に自由入力、負けた側のcoinが勝った側へ移る）
- 編成表、行動ログ、戦況、戦績、ランキングの表示

### 運営向け（ゲーム公開後）

- `/バトル中止`
  - 進行中・一時停止中のギルドバトルを、理由を記録して強制中止
- `/バトル再開`
  - 再起動後の点検で一時停止したギルドバトルを再開
