# 機能一覧

このファイルは「利用者から見える機能」を説明します。各機能を直すファイルは
[設計・開発ガイド](ARCHITECTURE.md#機能とコードの対応表)を参照してください。

## 利用者向け

- ATMパネル
  - 残高照会
  - 1,000 coin以上の送金
  - 送金メモ、受取人DM、運営ログ
- `/メンバー確認`
  - coin、VC時間、XP、招待ポイントなどの確認
- `/xp確認`
  - 月間・累計のVC時間とXPの確認
- `/ランキング`
  - coin、招待ポイント、VC時間、XP、アンケート評価の順位表示
- 招待ポイントパネル
  - ポイント確認
  - 精霊期間延長、宿屋無料率、coinへの交換
- 宿屋パネル
  - ツーショ、シークレット、プレミアムの作成
  - VC名、人数、公開状態、招待、出禁、共有の管理
  - 作成から15時間後の自動削除
- 問い合わせパネル
  - 問い合わせ先の選択と専用チャンネル作成
  - 終了後の再開、保存、削除
- 自己紹介チャンネル
  - 入力テンプレートの自動設置・再配置

## 評価員・運営向け

- `/召喚`
  - 精霊登録、クラス・期間設定、評価スレッド作成、ロール変更
- 評価パネル
  - 新規評価、追記、評価可能な対象者一覧
- 自動転生
  - 期限確認、評価保存、ロール変更、転生後アンケート
- `/転生`
  - 管理者による手動転生
- `/評価状況`
  - 総合評価に基づくクラス変更候補の表示
- `/クラス分布`
  - 現在のクラス別人数表示
- `/クラス変更`
  - ロール、DB、評価スレッドをまとめて更新
- `/招待報酬`
  - 招待ポイントの付与と利用ログ
- `/残高変更`
  - ユーザーまたはロール単位でcoin残高を変更
- `/ban`
  - ユーザーID指定のBANとログ保存

## 自動処理

- VC参加・退出・移動から滞在時間とXPを計算
- VC集計を5分ごと、およびBot終了時に保存
- 月替わりのVC・XP集計リセット
- ロール別coin月次報酬（停止期間後の追いつき・再実行時の二重支給防止）
- 負債状態に応じたロール変更
- 常設パネルが消えた場合の自動復旧
- メンバー参加・退出ログと関連データ整理
- 精霊期限とアンケート期限の定期確認
